Ответ предлагает одну согласованную библиотеку иконок со стилем линии (Lucide, при нехватке бизнес-иконок —
Tabler) и называет конкретные иконки для каждого из четырёх разделов. Для работы без сети иконки встраиваются
в приложение — SVG-спрайт или инлайн-SVG в сборке, кэшируемые сервис-воркером, — а не грузятся с CDN или
веб-шрифтом из интернета. Не засчитывать, если решение зависит от CDN во время работы.
