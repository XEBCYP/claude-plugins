# Шаблоны глобального проекта

`<…>` — подставить. Лишние разделы убрать, своё добавить.

## CLAUDE.md глобального проекта

```markdown
# <Имя> — глобальный проект

<Цель одной-двумя фразами.> Объединяет подпроекты, у каждого — своя задача; здесь — общая цель, план, связи между
подпроектами и интеграция. Кода подпроектов здесь нет — только ссылки на них.

## С чего начать сессию

1. `docs/Передача_сессии.md` — где остановились, что дальше. В конце сессии — обновить.
2. `docs/План.md` — цель и требования пользователя (дословно, с номерами R).
3. `docs/Подпроекты.md` — реестр: что каждый подпроект отдаёт глобальному, состояние, коммит последней сверки.
4. Открытые вопросы в панели «Ждут ответа» — напомнить пользователю о неотвеченных.
5. Если с последней сверки прошло время или пользователь просит — сверка подпроектов (навык `sreda:globalnyj-proekt`).

Термины — `GLOSSARY.md`; решения и почему так — `docs/adr/`.

## Связь с пользователем и подпроектами (ADR-<N>)

- Пользователь говорит только с этой сессией, по-русски; вопросы ему — окном с кнопками и в панель «Ждут ответа»,
  с пометкой подпроекта.
- С сессиями подпроектов — по-английски; они пользователя не спрашивают, вопросы шлют сюда. Слова пользователя —
  в заданиях дословно по-русски; документы для людей — по-русски.

## Новый подпроект

Папка со своим git, `CLAUDE.md` (первой строкой — ссылка на реестр), `docs/Задание.md`, строка в реестр, сессия в его
папке. Результат принимать по тому, что он должен вернуть (независимая проверка), затем — реестр и план.
```

## Сообщения между сессиями (по-английски)

Бриф при запуске сессии подпроекта:

```text
You are the <Subproject> subproject of the global project <Name> (<path>). Your task: <path to Задание.md> — read it
first, then CLAUDE.md. Quotes of the user stay in Russian. Do not ask the user: send questions to the global session
(<session id>) as one short message: what to decide, options, your recommendation and why. Work only in <folder>;
commit there. When done, report to the global session in 5–15 lines: what was done, where (commit/PR), what is not
verified, what you need from the user.
```

Вопрос подпроекта глобальной:

```text
Question for the user (<Subproject>): <what to decide, one sentence>. Options: A — <…> (recommended: <why>); B — <…>.
Blocked until answered: <yes/no, what waits>.
```

Ответ глобальной подпроекту:

```text
User's answer (<date>), verbatim: «<русская цитата>». In short: <translation>. Go ahead with <…>.
```
