# sreda — «Среда работы»

Весь способ работы пользователя с Claude в одном плагине, чтобы он стоял на каждом компьютере и не искался по частям.

| Часть | Что даёт |
|---|---|
| Навык `sreda:kak-rabotat` | Правила: разобраться до конца (код, базы, интернет, законы), решить и показать варианты с обоснованием, не применять без «да»; любой вопрос — окном с кнопками и в панель; слова пользователя дословно; замечания копить и исправлять одним прогоном; чужие системы — только по команде; секреты не вводить; PR сливать только по «да» на каждый; рискованные изменения сервера — сначала откат |
| Навык `sreda:globalnyj-proekt` | Глобальный проект и подпроекты: когда предложить (после постановки начальной задачи), устройство глобальной папки, новый подпроект с заданием, сессии подпроектов, порядок общения (с пользователем — по-русски, между сессиями — по-английски), приёмка и сверка; шаблоны файлов и сообщений |
| Панель «Ждут ответа» | Мод рядом с чатом: все неотвеченные вопросы с пояснениями и кнопками; не исчезает, пока не ответишь |
| Зависимости | `delivery-control` (контроль сдачи, `diagnose`) и `autohandoff` (передача в чистый контекст) включаются вместе с `sreda` |

Краткие правила попадают в `~/.claude/CLAUDE.md` установщиком маркетплейса (блок `xebcyp-plugins`), подробности — в
навыках. Местное (пути, диски, серверы, VPN) остаётся в `~/.claude/CLAUDE.md` компьютера вне блока.

## Панель «Ждут ответа»

Окно с вопросом в чате закрывается, если написать что-то, не нажав кнопку, и потом вопрос трудно найти в длинной
переписке. Панель показывает все вопросы, на которые ещё нет ответа: откуда вопрос (проект, подпроект), что решаем и
зачем, кнопки вариантов и что будет при каждом. Нажатие отвечает Claude так, будто ответ напечатали в чате, и убирает
вопрос из панели.

- Claude записывает вопрос в `~/.claude/zhdut-otveta.json` (общий для всех сессий компьютера) и одновременно задаёт
  его окном в чате. Ответили в чате — Claude ставит вопросу `"status": "answered"`.
- Ответ кнопкой уходит в ту сессию, где её нажали. В схеме с глобальным проектом пользователь отвечает в глобальной
  сессии, а она передаёт ответ подпроекту.
- Панель открывается сама в начале сессии; закрыли — команда `/zhdut-otveta`.

Формат файла:

```json
{ "items": [ { "id": "kratkij-kod", "from": "Проект или подпроект", "question": "Что решаем?",
  "why": "Зачем и что известно", "options": [ { "label": "Вариант", "desc": "Что будет" } ],
  "status": "open", "asked": "2026-10-24" } ] }
```

После ответа появляются `status: "answered"`, `answer` и `answeredAt`.

## Установка

```
/plugin install sreda@xebcyp-plugins
```

Установщик маркетплейса (`scripts/install.ps1`, `install.sh`) включает его сам. Отдельный плагин `zhdut-otveta`
заменён этим: из маркетплейса он убран, Claude Code удалит его сам; строку `zhdut-otveta@xebcyp-plugins` в
`~/.claude/settings.json` можно удалить.
