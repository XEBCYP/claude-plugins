# Глоссарий и решения (ADR)

Одинаково во всех проектах. Файлы создаются, **только когда появилось, что записать**. Если в проекте уже
есть своё место для этого (свод правил для бухгалтера, `docs/ОписаниеБазы`, раздел в CLAUDE.md), — пишем
туда и новых файлов не заводим.

## GLOSSARY.md — что значат слова проекта

В корне проекта. Только термины **этого** проекта, без деталей реализации и без общих понятий
программирования. Определение — одна-две фразы: что это **есть**, а не что делает. Синонимы, которыми
не пользуемся, — под «Не путать».

```markdown
# <Проект>

<Одна-две фразы: о чём проект.>

## Термины

**Остаток на дату**:
Количество и сумма по номенклатуре на складе на конец дня, по данным регистра остатков источника.
_Не путать_: сальдо (бухгалтерский термин, счёт 41), наличие.

**Партия**:
Поступление товара одним документом, от которого считается себестоимость списания.
_Не путать_: серия, документ поступления.
```

Когда писать: термин уточнили в разговоре; одно слово в разных местах значит разное (в 7.7 и 8.3, у
пользователя и в коде); пришлось объяснять одно и то же второй раз. Пользователь употребил термин не так,
как в глоссарии, — сразу спросить, какой смысл верный, и поправить.

## docs/adr/ — почему сделано так

Файлы `docs/adr/0001-<коротко>.md`, номера по порядку. ADR может быть одним абзацем:

```markdown
# Себестоимость при переносе — по средней, а не по партиям

Контекст, что решили и почему, в 1–3 фразах. Решение пользователя/бухгалтера ДД.ММ.ГГГГ: «…».
```

По желанию: `Статус: принято | заменено ADR-000N`, «Рассматривали» (если отвергнутые варианты стоит
помнить), «Последствия» (если неочевидны).

Писать ADR, только когда **все три** верны:
1. решение трудно отменить;
2. без пояснения читатель удивится, почему так;
3. был настоящий выбор между вариантами.

Решения пользователя и бухгалтера по учёту — почти всегда ADR: их трудно отменить, и без причины они
выглядят странно.

## Как пользоваться

- Перед планом и при разборе чужого кода — прочитать GLOSSARY.md и ADR той области.
- План и код говорят словами глоссария; противоречие с ADR — сказать, а не молча переделать.
- Решение поменялось — новый ADR со ссылкой «заменяет ADR-000N», старый — статус «заменено».
