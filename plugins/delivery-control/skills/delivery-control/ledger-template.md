# Шаблон файла требований

Файл: `docs/requirements/<ГГГГ-ММ-ДД>-<тема>.md` (или место, где проект уже держит такие записи).
Верхняя часть — постановка как есть; не правится никогда, только дописывается.

```markdown
# <Тема>: постановка и требования

## Постановка

> Записано <ГГГГ-ММ-ДД>. Текст не редактируется — с ним сверяется результат.
> Всё, что сказано позже, — в «Дополнения».

<текст пользователя дословно; ключи и пароли заменены на [СКРЫТО:ИМЯ_ПЕРЕМЕННОЙ]>

## Дополнения

- <ГГГГ-ММ-ДД> — «<дословно, что пользователь сказал по ходу>»

## Требования

| ID | Из постановки (дословно) | Статус | Основание | Где сделано |
|----|--------------------------|--------|-----------|-------------|
| R01 | «…» | готово | — | `src/…`, коммит abc1234 |
| R02 | «…» | заглушка | нет цен — пришлёт позже | отчёт |
| R03 | «…» | снято | пользователь <дата>: «SMS не надо» | — |
| R04i | *(подразумевается)* … | отложено | вне рамок: <почему> | отчёт |

## Решения

- <ГГГГ-ММ-ДД> — <что решили> — <кто: пользователь / бухгалтер / я, с причиной>

## Приёмка

- <ГГГГ-ММ-ДД> слепая приёмка: подтверждено N из M; расхождения: …
```

Статусы: `open` · `в работе` · `готово` · `заглушка` · `отложено` · `снято` (только словами пользователя).
Подразумеваемые — с `i`; ограничения, которые выяснились при работе, — `D01…` (не требование, не снимает
никакое R).
