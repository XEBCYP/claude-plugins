# zhdut-otveta — панель «Ждут ответа»

Окно с вопросом в чате закрывается, если пользователь написал что-то, не нажав кнопку, и потом вопрос трудно найти в
длинной переписке. Эта панель стоит рядом с чатом и показывает все вопросы, на которые он ещё не ответил: у каждого —
откуда вопрос (проект, подпроект), что решаем и зачем простыми словами, кнопки вариантов и что будет при каждом.
Нажатие отвечает Claude так, будто ответ напечатали в чате, и убирает вопрос из панели.

## Как пользоваться

- Claude записывает вопрос в `~/.claude/zhdut-otveta.json` (общий для всех сессий компьютера) и одновременно задаёт
  его окном в чате. Ответили в чате — Claude ставит вопросу `"status": "answered"`.
- Панель открывается сама в начале сессии; закрыли — команда `/zhdut-otveta`.

## Формат файла

```json
{ "items": [ { "id": "kratkij-kod", "from": "Проект или подпроект", "question": "Что решаем?",
  "why": "Зачем и что известно", "options": [ { "label": "Вариант", "desc": "Что будет" } ],
  "status": "open", "asked": "2026-10-24" } ] }
```

После ответа появляются `status: "answered"`, `answer` и `answeredAt`.

## Установка

```
/plugin install zhdut-otveta --marketplace XEBCYP/claude-plugins
```

Установщик маркетплейса (`scripts/install.ps1`, `install.sh`) включает его сам.
