# Изменения

Версия своего плагина — поле `version` в его `.claude-plugin/plugin.json`. Claude Code хранит установленный
плагин по номеру версии: **любая правка плагина — новая версия**, иначе на машинах, где он уже стоит, правка не
появится. Сторонние плагины обновляются сменой `sha` в `marketplace.json` и строкой в [AUDIT.md](AUDIT.md).

Как выпустить версию — [README.md](README.md#выпуск-версии).

## Не выпущено (ветка autohandoff-otschet)

- **autohandoff 2.1.0** — передача без ожидания пользователя: в конце хода, когда задача закончена (или с верхнего
  порога — без проверки), полоса над полем ввода «через 5 с передам» с кнопками «Пауза», «Передать», «Отменить»;
  никто не нажал — передача. Окна «Передать?» больше нет. Новая сессия пересказывает итог прошлой задачи и заново
  задаёт открытый вопрос окном. Настройка `countdown`. ADR 0010. Тесты 20/20.
- **sreda 1.2.4** — `globalnyj-proekt`: пороги автопередачи описаны по-новому (без «вопроса с 250»).

## Не выпущено (ветка autohandoff-percent-guard)
