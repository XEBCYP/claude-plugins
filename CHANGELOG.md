# Изменения

Версия своего плагина — поле `version` в его `.claude-plugin/plugin.json`. Claude Code хранит установленный
плагин по номеру версии: **любая правка плагина — новая версия**, иначе на машинах, где он уже стоит, правка не
появится. Сторонние плагины обновляются сменой `sha` в `marketplace.json` и строкой в [AUDIT.md](AUDIT.md).

Как выпустить версию — [README.md](README.md#выпуск-версии).

## Не выпущено (ветка autohandoff-tokens)

- **autohandoff 2.0.0** — пороги в тысячах токенов вместо процентов окна: искать момент со 150 тыс., вопрос с
  250 тыс., «Не сейчас» — +50 тыс.; глобальная сессия (папка с `docs/Подпроекты.md`) — 120 / 180 / +30 тыс. Настройки
  `from`, `to` теперь в тысячах токенов, новые — `askStep`, `globalFrom`, `globalTo`, `globalAskStep`. Отметки сессий
  из 1.x (в процентах) не берутся — мод начинает их заново. ADR 0008.
- **sreda 1.1.0** — раздел 9 «Расход токенов» в `kak-rabotat`; в `globalnyj-proekt` — пороги передачи, субагенты
  внутри подпроектов, вопросы пачкой, сверка по просьбе или не чаще раза в день. Отключение ненужных подключённых
  сервисов — записано как отложенное решением пользователя.
- Блок `templates/user-CLAUDE.md` — строка о порогах передачи.

## Не выпущено (ветка sreda)

- **sreda 1.0.0** — «Среда работы»: навык `kak-rabotat` (правила работы с пользователем в одном тексте), навык
  `globalnyj-proekt` (глобальный проект и подпроекты, сессии, порядок общения, приёмка и сверка; шаблоны), панель
  «Ждут ответа» (перенесена из `zhdut-otveta`, файл вопросов тот же — `~/.claude/zhdut-otveta.json`). Зависимости —
  `delivery-control` и `autohandoff`. ADR 0007.
- **zhdut-otveta** — убран из маркетплейса: вошёл в `sreda`. Плагины, убранные из маркетплейса, Claude Code удаляет
  сам (раздел Flagged в `/plugin`); если старая копия ещё включена — выключить её, иначе панели будет две.
- Блок общих правил `templates/user-CLAUDE.md` — короткие правила со ссылкой на `sreda`; в него перенесены общие
  разделы «Решения» и «Как работать» из личного `~/.claude/CLAUDE.md`.
