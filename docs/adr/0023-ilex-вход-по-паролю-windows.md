# ilex — программа входит сама по паролю из Windows

Статус: принято — 30.10.2026 пользователь: «Одна из сессий пишет, что вход по паролю истек, уже не может зайти. Тогда
давай переделаем этот скилл или этот мод, или что там, чтобы пароль был записан где-то в Windows или где, чтобы меня
каждый раз не просили по-новому зайти. Один раз я ввел, и все, и все сессии пользуются.» и «Глобальная сессия писала,
что там нету, не сохранились логин и пароль для входа. Поэтому их надо сохранить куда-то так, чтобы вы могли доставать
его сами.» Выбран вариант «Программа с паролем (рекомендую)». На вопрос «Кто, кроме нас, входит в ilex под этой
учёткой?» — «Пользуются у заказчика». Выпуск: sreda 1.22.0. Заменяет в ADR 0022 строку сравнения «сессия входит сама —
нет» и пункт «Не вошло» про хранение пароля в Windows; остальное в ADR 0022 действует.

## Что нашли

- Вход во встроенном браузере с «Запомнить меня» слетает: ilex пускает под одной учёткой **один вход**. Новый вход
  показывает окно «Под данной учетной записью уже осуществлен вход в ilex. После нажатия кнопки "Продолжить"
  предыдущая сессия будет принудительно завершена.» (код сервера 971). Вход сотрудника заказчика выбивает сессии, и
  наоборот.

## Сравнение (показано пользователю)

| Способ | Кто вводит пароль | Вход потерян | Сотрудник заказчика | Допустимо для Claude |
|---|---|---|---|---|
| Программа `ilex.py` берёт пароль из диспетчера учётных данных Windows и входит сама | программа; пароль кладёт пользователь один раз `cmdkey` | программа входит снова (частота — порог, см. ниже) | выбивается при каждом повторном входе программы | да: Claude пароль не видит и не вводит |
| Как было: пользователь входит во встроенном браузере | пользователь, каждый раз | сессия просит войти | выбивается при каждом входе пользователя | да, но просит пользователя снова и снова |
| Claude вводит пароль в браузере сам | Claude | — | — | нет: правило безопасности и правило пользователя «логины и пароли самому не вводить» |

## Решение

| № | Что | Где |
|---|---|---|
| 1 | Пароль — в диспетчере учётных данных Windows, общие, цель `ilex`; кладёт пользователь: `cmdkey /generic:ilex /user:<почта> /pass` | сделано пользователем 30.10.2026 |
| 2 | Программа `ilex.py` (Python + playwright, установленный Edge, свой профиль `%LOCALAPPDATA%\ilex-client\profile`): `search`, `doc --find`, `status`; пароль читает `CredReadW`, никуда не печатает | `plugins/sreda/skills/normativka/ilex.py` |
| 3 | Вход — только когда вход потерян (страница входа или окно `forced-logout-dialog`, ждать переадресацию до 6 с) ; порог частоты `MIN_RELOGIN_MINUTES` = 0 — без ограничения («сейчас любое количество раз» (пользователь, 30.10.2026)); при пороге больше 0 в лимит идут удачный вход и вход с нажатым «Продолжить», неудачный — нет; окно «Продолжить» программа подтверждает; каждый вход — в `log.txt`. Вход потерян посреди `search`/`doc` — войти и повторить раз | `ilex.py` |
| 4 | Коды выхода 2/3/4/5/6 и что сказать пользователю; при коде 3 пользователя не просить войти (вход у сотрудника заказчика); встроенный браузер — запасной путь, когда программы нет или страница не грузится; `status` только смотрит, не входит | навык `normativka` |
| 5 | Одновременные запуски из разных сессий ждут друг друга (lock, до 90 с — меньше тайм-аута команды сессии, потом код 6) | `ilex.py` |

## Не вошло и не проверено

- Сценарий «выбили, прошёл час, вход снова» и код 3 на живом ilex не проверены (проверены вход с «Продолжить», поиск,
  чтение документа, `status` без входа и код 2): проверка выбила бы сотрудника заказчика. Признак потери входа —
  по коду сайта (окно `il-forced-logout-dialog` на странице входа).
- Порог показан пользователю диапазоном 15/30/45/60/90/120 мин (за 8 часов можно выбить сотрудника 32/16/~10/8/~5/4
  раза; сессия ждёт до порога); ответ — «сейчас любое количество раз» (пользователь, 30.10.2026). Если у заказчика пожалуются — поставить 60.
- Не проверено, разрешают ли условия ilex автоматический доступ.
- Предложено, не сделано: попросить у заказчика отдельный вход в ilex для сервера — тогда сессии и сотрудники не
  выбивают друг друга.
- Программа работает только там, где есть Python 3.13 с playwright и Edge (сервер EM-WIN-160).
