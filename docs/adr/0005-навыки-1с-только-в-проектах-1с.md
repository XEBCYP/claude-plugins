# Навыки 1С включаются только в проектах 1С, а не глобально

Статус: принято — решение пользователя 2026-10-16 (П01 аудита: «выключить `1c-skills` в общем шаблоне и
включать его в `.claude/settings.json` проектов 1С»).

`1c-skills` — 81 навык и ~3,5 тыс. токенов описаний в каждой сессии. Включённый везде, он переполнял список
навыков: у остальных навыков (`delivery-control`, `diagnose`, `ui-icons`, `data-skills`) модель видела только
имя без описания, и они переставали срабатывать сами. Общий шаблон `templates/user-settings.json` теперь
выключает `1c-skills` и `1c-skills-py`; их включает шаблон проекта (ADR 0004).

Последствия: где навыки 1С уже включены глобально, установщик это не меняет (показывает расхождение с
шаблоном) — выключить в `/plugin`.
