# ilex — глубокое изучение темы по ссылкам и чтение длинных документов целиком

Статус: принято — 30.10.2026 пользователь (дословно, главное): «посмотри на встроенном браузере, разберись, там есть
возможность переходить по ссылкам из документа в документ… выработай правила и механизм, чтобы все сессии, которые
подключают этот скилл и подключаются к Алексу, полноценно изучали. Не просто прокрутили одну страничку или скачали еще
проще документ и все.» Плюс задача сессии «1С экспорт: учет и регистры»: `ilex.py doc` теряет середину длинного
документа (закон 57-З, ст. 10). План показан окном со сравнением, выбран «Да, делай так (рекомендую)». Выпуск: sreda
1.24.0. Разведка — `docs/ilex-razvedka-2026-10-30.md`.

## Решение

| № | Что | Где |
|---|---|---|
| 1 | `doc` — всегда весь текст через «Экспорт в Word» (RTF разбирается в программе, файл сразу удаляется), запас — прокрутка (до 150 с, предупреждение, если конец не собран); `--full` — для совместимости. Первоначально весь текст был только с `--full`; по итогам независимой проверки 30.10.2026 стал поведением по умолчанию, чтобы `doc <ссылка>` по привычке не терял середину | `ilex.py` |
| 2 | `doc --links [--find]` — абзацы с номерами и ссылки документа (абзац, тип РДД/НУЛ/ПОТ/ИЗА/УМС, текст, адрес) | `ilex.py` |
| 3 | `backlinks <ссылка> [--seg] [--tab] [--page]` — кто ссылается на абзац: число по вкладкам, список по 25 | `ilex.py` |
| 4 | `editions <ссылка>` — редакции с датой и состоянием | `ilex.py` |
| 5 | Порядок изучения (поиск → норма целиком → редакция → абзац и его ссылки → кто ссылается → до 6 материалов, 2 шага → запись) | навык `normativka` |

## Проверено (30.10.2026, закон 57-З BELAW/238448)

— «ничего нет»; `--page 2`; `editions` — 8 редакций; статья BEPBI/106097 через Word.
