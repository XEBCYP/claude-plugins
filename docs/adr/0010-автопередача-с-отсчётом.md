# Автопередача — с отсчётом и паузой, без ожидания пользователя

Статус: принято — решение пользователя 2026-10-25: «Пусть он ждет моего ответа буквально 5 секунд, если я не нажал
кнопку «отменить», либо никак не отреагировал, … то он автоматически передает информацию в новую сессию, старую
очищает»; «можно добавить кнопку "пауза" при нажатии ничего не передается и не меняется, после того как я дочитал,
нажму отправить».

## Что было

`autohandoff` 2.0 передавал работу сам только по следующему сообщению пользователя после законченной задачи, а с
верхнего порога (250 тыс., в глобальной — 200) открывал окно «Передать?» и ждал ответа. Пользователь отходит от
компьютера — окно висит, сессия копит контекст и не передаётся.

## Решение

- В конце хода, без сообщения пользователя: тот же удачный момент (ход не прерван, нет фоновых агентов, проверка по
  разговору «можно без потерь»; вопрос в итоговом окне не мешает — он уходит в документ) → полоса над полем ввода:
  «через N с передам работу в чистый контекст», кнопки «Пауза», «Передать», «Отменить». Никто не нажал — передача.
- «Пауза» — отсчёт стоит, ничего не меняется; передача — кнопкой «Передать» или новым сообщением.
- С верхнего порога — та же полоса в конце хода, без проверки момента. Окна «Передать?» нет; посреди хода не
  передаём.
- «Отменить» — полосы нет до +`askStep` тыс. токенов (50, в глобальной — 30), как прежнее «Не сейчас».
- Сообщение пользователя при полосе — передача с ним (момент уже проверен); ответ на вопрос итогового окна — в эту же
  сессию.
- Последний ответ после `/clear` пропадает с экрана: документ передачи хранит итог задачи и заданный вопрос дословно,
  новая сессия начинает с пересказа и задаёт вопрос заново окном (он попадает в панель «Ждут ответа»).
- Отсчёт — настройка `countdown`, по умолчанию 5 с (слова пользователя). Изменено 2026-10-27 (autohandoff 2.2.1):
  15 с — пользователь: «времени не хватает, хочу увеличить эту задержку», выбрал «15 секунд».

## Почему

Передача без потерь — документ пишет сама сессия, пока всё помнит; ждать пользователя ради неё не нужно.
Отсчёт и пауза оставляют пользователю, который сидит за компьютером, время дочитать и отменить.
