# onec-odata: запись в базу 1С — только после подтверждения

Статус: принято (2026-10-16).

У MCP-сервера aprovodka по умолчанию запись в базу ничем не ограничена (`ONEC_WRITE_MODE=off`). Плагин задаёт
`ONEC_WRITE_MODE=approval`: любое изменение сначала показывается как предпросмотр и выполняется только после
подтверждения. Ошибочная запись в учётную базу дорога, а чтение покрывает большинство задач.

Рассматривали: `preview` (запись только предпросмотром, выполнить нельзя) — отвергнуто, иногда запись нужна;
`off` (по умолчанию у пакета) — отвергнуто как опасное.
