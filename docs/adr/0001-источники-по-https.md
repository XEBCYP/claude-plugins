# Маркетплейсы подключаются по HTTPS, а не через `github`/SSH

Статус: принято (коммит `de51d6e`, 2026-10-16).

Источник `"source": "github"` клонируется по SSH и требует ключ, которого нет в облачных сессиях и на новых
машинах. Поэтому и маркетплейс, и сторонние плагины указаны как `git`/`url` с адресом `https://…`; приватный
доступ, если понадобится, даёт `gh auth setup-git` (установщик делает это сам, когда `gh` авторизован).

Последствия: у машин, поставленных до перехода, в `settings.json` оставался старый источник — с П07 аудита
2026-10-16 установщик заменяет `source` у записи `xebcyp-plugins` при повторном запуске.
