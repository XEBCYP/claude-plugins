# Хуки и плагины по итогам аудита недели 20–27.10.2026 (пакет 3)

Статус: принято — решение пользователя 2026-10-27: после пакетов 1 и 2 (ADR 0014) на вопрос «что дальше» выбран
«Пакет 3 (рекомендую)», затем план из восьми пунктов — «Да, все 8 (рекомендую)». Выпуск: sreda 1.9.0, autohandoff
2.3.0, один перезапуск программы. После слепой проверки — исправления по её находкам, решение пользователя «Да, все 6
(рекомендую)», и фильтр пробуждений убран из выпуска — «Убрать фильтр (рекомендую)».

## Решение

Правила, которые не соблюдались словами, держит сам плагин:

| № | Что | Где | Случай недели |
|---|---|---|---|
| 1 | «git add -A / . / --all / -u / * / :/», «git commit -a» не выполняются, если в границах команды есть изменённые файлы, которые сессия не правила (Write/Edit); Claude видит список и добавляет свои по именам. `commit -a` и `add -u` смотрят только файлы под git, `add -A -- папка` — только папку. Команда разбирается как оболочка (кавычки, heredoc, here-string): слова в сообщении или echo — не команда | sreda, `hooks/git.ts` | 25.10 Export1c7: `git add -A` забрал файлы параллельной сессии (d5957d0); ~315 таких команд в ~116 сессиях |
| 2 | «git commit -m» с кириллицей в самом сообщении (и многострочном: heredoc, `@'…'@`; и после `git add -A &&`) не выполняется — подсказка `-F файл`. Русские имена папок и файлов в команде не мешают | sreda, `hooks/git.ts` | упоминается в 11–14 передачах |
| 3 | Жёсткий предел 300 тыс. (`hard`): после действия основного цикла мод отменяет ход (`$.turn.abort`) и передаёт; документ пишет, на каком шаге остановились. Не пока работают субагенты и не сверх лимита попыток в час | autohandoff | R50 25.10 — 10 ч, контекст до ~860 тыс., 639 млн токенов; 27.10 — 330 млн |
| 4 | Сообщение другой сессии или событие с верхнего порога не сбрасывает полосу: передача, сообщение — следом; отсчёт, поставленный пользователем на паузу, событие не прерывает. Сессия подпроекта передаёт без отсчёта | autohandoff | каждое пробуждение снимало отсчёт, и передача не наступала |
| 5 | Сообщения других сессий во время передачи придерживаются и уходят в чистую сессию после документа; пометка «от другой сессии» — только у сообщений сессий и уведомлений, нажатие кнопки — как сообщение пользователя | autohandoff | «in case the earlier message got lost across your handoff» |
| 6 | Пробуждения глобальной (`<side-sessions-event>`) — в журнал `~/.claude/sreda-probuzhdeniya.json` с пометкой «шум» (догадка); фильтр — отдельным выпуском, правила — по записи | sreda, `hooks/probuzhdeniya.ts` | 84 пустых пробуждения, 10–15 млн токенов; отчёт R50 «Prompt dropped by a hook…» |
| 7 | С 60 действий за ход — напоминание довести шаг и закончить ход, дальше через 30 (`steps`, `stepsEvery`) | autohandoff | ходы на 200–330 действий, в среднем 28 на сообщение |
| 8 | Пауза — состояние сессии: `/pauza` или «поставь на паузу», «нужно перезагрузить» в глобальной; на паузе окна вопросов и запуск сессий не пропускаются; `/prodolzhit` или «продолжай» снимает. Хранится по папке глобального проекта — переживает перезапуск и передачу в чистую сессию; в других сессиях `/pauza` — подсказка | sreda, `hooks/pauza.ts` | 25.10 после «пауза» глобальная прислала два окна по установке |

## Почему так

- **Отказ, а не предупреждение** (1, 2): предупреждение модель читает после выполнения команды — чужие файлы уже в
  коммите. Отказ стоит одного лишнего шага. Ложный отказ (файл правили через оболочку, плагин перезагружен) тоже стоит
  одного шага: свои файлы — по именам.
- **Предел через отмену хода** (3): напоминание с `to` (2.2.0) модель может не выполнить, а каждое действие на 500+
  тыс. стоит как два на 250. Точка отмены — после законченного действия: команда уже вернула результат; фоновые команды
  и копирования документ передачи велит проверить.
- **Фильтр сначала в режиме записи** (6): по журналу сессий нельзя было уверенно отличить, доходят ли отчёты
  подпроектов до хука в тексте сообщения. Если не доходят, фильтр счёл бы шумом каждое пробуждение и глобальная
  перестала бы узнавать о подпроектах. Поле `head` в журнале показывает, что видит хук. Правила шума, написанные
  заранее, проверка признала догадкой (непривычный текст события счёлся бы шумом) — фильтр делается по записи.
- **Пауза только в глобальной** (8): слова «нужно перезагрузить» в обычной сессии — часть задачи (сервер, служба).

## Не вошло

- Предупреждение при `git add -A` без чужих файлов — молча пропускается: шума больше, чем пользы.
- Предел 300 тыс. не срабатывает сверх лимита попыток в час (`perHour`) и при выключенной автопередаче — защита от
  передач по кругу; сверх лимита контекст может расти.
- Рассылка паузы самим плагином: её делает модель (SendMessage) по сообщению плагина — адресатов знает глобальная.
- Пакеты 4–7 аудита — не согласованы.
