# Автопередача контекста — свой мод вместо handoff

Статус: принято — решение пользователя 2026-10-24 («сделать новый мод вместо HandOff», продолжение — `/clear`
в том же окне, установка через этот маркетплейс).

Мод `handoff` (сторонний, nickvels-mods) на 60 % контекста спрашивал кнопкой и переносил работу в чистый
контекст в любой момент, даже посреди задачи; шаблон документа передачи был коротким. Нужно было: автоматически,
на 30–50 %, и только когда передача ничего не теряет.

Решения:

- **Момент — следующее сообщение пользователя после законченной задачи.** Признаки: ход не прерван, итоговое окно
  приложения (`wrap_up`) без вопроса, нет работающих агентов, и `$.model.fork` по самому разговору отвечает «ДА».
  Передача на сообщении, а не сразу в конце хода, — чтобы `/clear` не стёр ответ, который пользователь ещё не прочитал.
- **Продолжение — `/clear` в том же окне**, а не архив и новая сессия: работает и в приложении, и в терминале;
  разговор остаётся на диске. Вызвать из мода инструменты приложения «создать сессию» и «архивировать» не проверено.
- **Документ пишет Claude обычным ходом (навык), а не `$.model.fork`**: ход может прочитать `git status` и обновить
  файл передачи проекта, если его требует CLAUDE.md.
- **С 50 % — вопрос кнопкой**, как в `handoff`: дальше ждать удачного момента дорого.

Последствия: `handoff@nickvels-mods` выключается там, где ставится `autohandoff`, иначе на 60 % будет два вопроса
и два `/clear`.
