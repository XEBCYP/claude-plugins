# Диапазон усилий — от среднего до сверхвысокого, только Opus 5.5

Статус: принято — решение пользователя 2026-10-27: «…давай поменяем диапазон усилий, которые может менять среда.
Давай теперь максимальный диапазон, это будет уровень сверхвысокий, а низший уровень средний. Давай поработаем в этом
диапазоне. То есть при необходимости плагин может включать и сверхвысокий уровень, а самый низкий будет средний. И
всегда используется Opus 5.5. … Не в конфигуратор, а в плагин.»

Меняет рамки ADR 0011 (было: Sonnet 5.5 и Opus 5.5, низкий — высокий). Ручной режим (ADR 0012) — без изменений.

## Решение

- **Своя сессия:** уровни `medium` / `high` / `xhigh`. Оценка сообщения считает признаки сложности: длинное
  (больше 1500 знаков), три вопроса и больше, четыре пункта и больше, слова о поиске ошибок и решениях, слова о
  неудачной прошлой попытке («не помогло», «всё ещё не», «до сих пор не»; со словами о поиске ошибок не
  пересекаются — одна фраза не даёт двух признаков). Один признак — высокий, два и больше —
  сверхвысокий, без признаков — средний (механика тоже: ниже среднего нет). Строка `Effort: …` в задании подпроекту —
  с `xhigh`; `low` → средний, `max` → сверхвысокий. Инструмент `uroven` — `medium | high | xhigh`.
- **Агенты и подпроекты:** любая модель → Opus 5.5 (Sonnet, Haiku, Fable); `Explore` без модели — Opus;
  `start_session` без модели — Opus явно (иначе новая сессия взяла бы модель глобальной); уровень
  `low` → средний, `max` → сверхвысокий. Слепая проверка — по-прежнему Opus высокий (правило пользователя в CLAUDE.md).
- **Модель своей сессии** мод по-прежнему не меняет: смена сбрасывает кэш переписки, а запасная модель при перегрузке
  должна работать. На какой модели открывается новая сессия, выбирает программа (её настройка модели); сессии,
  запущенные из другой сессии, мод ставит на Opus. Сам `xhigh` уходит и на запасную модель, если программа на неё
  переключилась, — поддерживает ли она его, не проверено.

## Почему так

Два признака — сверхвысокий, а не отдельный список «трудных» слов: «почему», «ошибка» встречаются в обычных
просьбах, а сочетание ошибки с неудачной попыткой или с большим объёмом — признак трудной задачи. Сверхвысокий
дороже, а понижение на длинной переписке идёт только со второго простого сообщения подряд (ADR 0011), поэтому
одного слова для него мало.
