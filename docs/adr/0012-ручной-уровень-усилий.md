# Ручной уровень усилий — мод не перебивает выбор пользователя

Статус: принято — решение пользователя 2026-10-27: «По некоторым проектам я бы хотел иметь возможность самостоятельно
включать усилия без влияния плагина. … Чтобы плагин не понижал. Допустим, я хочу повысить усилия, а плагин его
понижает, исходя из своих доводов, размышлений. В каких-то проектах я бы хотел эту возможность плагина отключить.»
Из вариантов выбрано «Всё вместе».

## Что было

`sreda` (ADR 0011) подменял effort в каждом запросе основной сессии своим уровнем (`turn.step`) и не пускал выше
«высокого». Уровень, выбранный пользователем в программе, до модели не доходил; выключателя не было.

## Решение

- **Ручной режим проекта:** `.claude/sreda.json` в папке проекта, `{"uroven": "ручной"}`. Мод читает его в начале
  сессии. Файл проекта (а не настройка плагина) — его можно закоммитить, режим будет на всех ПК.
- **Команда** `/uroven ручной | авто` пишет этот ключ, сохраняя прочие; `/uroven` без слова — кто выбирает сейчас.
  Удалять файлы мод не умеет — «авто» записывается словом.
- **Сам — по выбору пользователя:** `e.effort` в `turn.step` — настройка сессии (не наша подмена); сменилась с прошлого
  запроса — её сменил пользователь, и до конца сессии мод уровень не трогает. `/uroven авто` возвращает.
- В ручном режиме: запрос уходит с уровнем программы как есть (без потолка «высокий»), оценка сообщений не идёт,
  инструмент `uroven` отказывает, строка — «вручную · <уровень>».
- Крайние случаи (по слепой приёмке): ручной режим сессии и уровень программы хранятся в состоянии сессии — перезагрузка
  плагина их не сбрасывает; точка отсчёта до первого запроса — уровень из настроек программы, если он там есть (иначе
  первый запрос); смена модели на том же запросе (запасная модель, `/model`) — не выбор уровня; файл проекта не
  JSON-объект — команда его не перезаписывает, BOM в начале не мешает.
- Рамки агентов и подпроектов (Haiku → Sonnet, Fable → Opus, слепая проверка — Opus высокий) не меняются.

## Почему

Список проектов в настройке плагина отброшен: он живёт на одном компьютере и правится руками. Только «уступать
выбору» — каждую новую сессию пришлось бы переключать заново; только файл проекта — в остальных проектах мод
по-прежнему перебивал бы выбор.
