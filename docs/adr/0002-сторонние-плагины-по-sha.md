# Сторонние плагины закреплены по коммиту (`sha`)

Статус: принято (2026-10-16).

Код сторонних плагинов (`1c-skills`, `1c-skills-py`, `bsl-language-server`, `dbhub`) исполняется на машине
пользователя: скрипты, хуки, MCP-серверы. Ссылка на ветку принесла бы любое изменение автора без проверки.
Поэтому в `marketplace.json` у каждого — проверенный `sha`; обновление — только через проверку нового коммита и
строку в [AUDIT.md](../../AUDIT.md).

Рассматривали: ссылку на ветку (`ref`) — отвергнуто, обновления приходили бы непроверенными. Слежение за новыми
коммитами — еженедельная проверка в CI (П13 аудита).
