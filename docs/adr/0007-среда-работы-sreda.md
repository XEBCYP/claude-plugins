# Среда работы — один плагин sreda

Статус: принято — решение пользователя 2026-10-24 (через сессию глобального проекта): «собрал какой-то один
механизм … чтобы не выискивать потом по частям»; механизм глобального проекта «применял сам» и «рекомендовал его
применение после постановки первоначальной задачи».

Способ работы пользователя был разбросан: часть правил — в блоке `templates/user-CLAUDE.md`, часть — только в личном
`~/.claude/CLAUDE.md` одного компьютера и в памяти отдельных проектов; схема «глобальный проект и подпроекты» — только
в CLAUDE.md и ADR одного проекта; панель вопросов — отдельный плагин `zhdut-otveta`.

Решения:

- **Один плагин `sreda`** с двумя навыками и панелью: `kak-rabotat` — все общие правила одним текстом (по-русски:
  его читает пользователь); `globalnyj-proekt` — когда предлагать схему, устройство, подпроекты, сессии, порядок
  общения, приёмка и сверка, шаблоны. Имён заказчиков, серверов и путей конкретного компьютера в плагине нет.
- **Панель «Ждут ответа» переезжает в `sreda`**, `zhdut-otveta` убирается из маркетплейса. Файл вопросов прежний
  (`~/.claude/zhdut-otveta.json`) и команда прежняя (`/zhdut-otveta`) — ничего не ломается у сессий, которые уже
  пишут туда вопросы. Убранный из маркетплейса плагин Claude Code удаляет сам.
- **`delivery-control` и `autohandoff` — зависимости `sreda`** (`dependencies` в `plugin.json`): включённый `sreda`
  включает и их, но они остаются отдельными плагинами — у каждого свои версии и тесты.
- **Блок `templates/user-CLAUDE.md` — коротко, подробно — в навыках.** Блок всегда в контексте, поэтому в нём
  остаются краткие правила и указание, когда звать навыки; общие разделы «Решения» и «Как работать» из личного
  `~/.claude/CLAUDE.md` перенесены в блок. В личном файле остаётся только местное: сервер, диски, VPN, глобальные
  проекты этого компьютера.

Последствия: после установки новой версии блока разделы «Решения» и «Как работать» вне блока в личном
`~/.claude/CLAUDE.md` повторяют блок — их убирают из личного файла.
