# Правила по итогам аудита недели 20–27.10.2026

Статус: принято — решение пользователя 2026-10-27: на просьбу «Проведи, пожалуйста, аудит всех моих проектов… Может
быть, стоит создать какие-то новые правила, которые помогут избежать ошибок, которые уже были у нас» аудит предложил
пакеты; пользователь выбрал «Пакеты 1 и 2» (уборка и правила).

## Решение

Новые правила (полный текст — `sreda:kak-rabotat` и `sreda:globalnyj-proekt`, кратко — блок шаблона
`templates/user-CLAUDE.md`), каждое против случая недели:

| Правило | Случай |
|---|---|
| Не выяснять заново: сначала список пунктов, ADR, база знаний | «ты ее уже делал не раз»; закрытые пункты всплывали как открытые |
| Выводы — по полным данным; сначала минимальный прогон | вывод по нескольким счетам; план перепроводить квартал помесячно |
| Сначала доступ, закрытое — сказать до работы | исправление молча ушло в копию вместо рабочей базы |
| Результат для пользователя — отрисовать и посмотреть; хранить в проекте | отчёт PDF с плохой вёрсткой, пропал вместе с папкой обмена |
| Своя папка и свои файлы; worktree — внутри проекта, удалять при слиянии | `git add -A` забрал файлы параллельной сессии; сессии R50 из папки глобального; 9 слитых worktree |
| Пауза — только состояние и «можно перегружать» | после «пауза» пришли новые окна установки |
| Одна проверка — один владелец, по номеру версии | глобальная записала «200», а новая версия не встала |
| Общее для подпроектов — в одном файле; ADR — с проектом | одно правило в четырёх репозиториях; разные ADR-0018 |
| Сверка — и «не отправлено в GitHub» | глобальный впереди GitHub на 133 коммита, у подпроекта нет удалённого |
| Выпуски плагинов — пакетом, не чаще раза в день | 22 версии sreda за 4 дня, восемь просьб о паузе ради перезагрузки |

Устаревшее и расхождения: кнопка «Скопировать команду» в панели (убрана в 1.5.3) — описание исправлено; «спрашивать с
250 тыс.» — с autohandoff 2.1.0 вопроса нет; история версий 1.5.5–1.5.6 убрана из правила; объём независимой проверки —
средние и большие задачи (как в `delivery-control`); в шаблон добавлены два правила, которые были только в
установленном файле («Закон: задание исполнителю…», «Отчёты нарастающим итогом…»).

## Не вошло

Хуки (запрет `git add -A` при чужих изменениях, кириллица в `commit -m`), автопередача на всех ходах, документы
передачи, скрипт покрытия требований, скрипт выкладки — следующие пакеты аудита, отдельным согласием. Автозамену
`powershell.exe` на `pwsh` не делать: 32-битный Windows PowerShell нужен для OLE 1С 7.7.
